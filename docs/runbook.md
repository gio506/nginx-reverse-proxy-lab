# Nginx Reverse Proxy Lab — Runbook

## Overview

This lab runs an Nginx reverse proxy with two Flask backends, TLS termination, rate limiting, and security headers. Three environments are provided: `dev`, `main`, and `prod`.

## Prerequisites

- Docker Desktop (or Docker Engine + Docker Compose plugin)
- `openssl` for local self-signed certificate generation
- `shellcheck` + `yamllint` for local linting

---

## Quick Start

```bash
# 1. Generate self-signed TLS certs (required before any docker compose up)
bash ./scripts/generate-certs.sh

# 2. Boot the dev stack
docker compose -f docker-compose.yml -f docker-compose.dev.yml up --build -d

# 3. Verify the stack is healthy
docker compose ps

# 4. Run smoke tests
LAB_MODE=dev bash ./scripts/smoke.sh

# 5. Run header checks
bash ./scripts/headers-check.sh

# 6. Tear down
docker compose -f docker-compose.yml -f docker-compose.dev.yml down --remove-orphans --volumes
```

## Environment Configs

| File | Environment | Purpose |
|---|---|---|
| `docker-compose.yml` | base | Shared services (app1, app2, nginx) |
| `docker-compose.dev.yml` | dev | Dev overrides |
| `docker-compose.main.yml` | main | Staging overrides with extended headers check |
| `docker-compose.prod.yml` | prod | Production overrides with rate-limit enforcement |

---

## TLS Certificates

Self-signed certs are generated by `scripts/generate-certs.sh` and placed in `nginx/certs/`.  
**Never commit real certificates.**

```bash
bash ./scripts/generate-certs.sh
```

---

## Rate Limiting

Configured in `nginx/conf.d/rate-limit.conf`:
- Zone: `perip`, 10 MB shared memory
- Rate: 3 requests/second per IP
- Burst: 10 requests with `nodelay`
- Status: `429 Too Many Requests`

## Health Checks

All backend services expose `/health`. Nginx is checked via `wget` on port 80.

```bash
# Check nginx directly
docker exec nginx-reverse-proxy-lab-nginx-1 wget -qO- http://127.0.0.1/health
```

## Troubleshooting

| Problem | Resolution |
|---|---|
| `nginx: [ssl] no certificate` | Run `scripts/generate-certs.sh` first |
| Container in `starting` state | Wait 10–15s for healthchecks; check `docker compose logs` |
| 502 Bad Gateway | Backend not healthy — run `docker compose ps` |
| Smoke test fails with TLS error | Self-signed cert — pass `-k` to curl or use `--insecure` |
| Port 80/443 already in use | Change host ports in the override compose file |
